Финальная работа по модулю "Сети"

Цель финальной работы:
Создать проект логической сети с использованием центра сертификации и фаерволом.

Что входит в финальную работу:
Создание сети в Cisco Packet Tracer. 
Создание центра сертификации.
Создание правил для фаервола. 
Перед вами стоит задача применить всё изученное в разделе и выполнить настройку своей сети. В сети предприятия должны быть выполнены следующие условия:

В компании 20 персональных компьютеров.
В компании четыре отдела: отдел IT (три ПК), отдел кадров (пять ПК), отдел продаж (два ПК), офис.
Каждый отдел находится в своём VLAN: отдел IT (VLAN 10 — IT), отдел кадров (VLAN 20 — Persona), отдел продаж (VLAN 30 — Sales), офис (VLAN 40 — SkillBox).
В офисе есть свой сервер. Он находится в IT-отделе. Отдел создаёт свои обновления в системе. На сервере нужно реализовать FTP-соединение и сделать из сервера центр сертификации.
Вся сеть охраняется фаерволом. Нужно поставить в виде сервера и произвести его настройку в iptables.
Помимо прочего, в сети есть гостевая сеть для вывода в интернет пользователей по Wi-Fi. Обеспечивать безопасность гостевой сети не требуется.
