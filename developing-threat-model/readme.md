Разработка модели угроз для учебной АСУТП
Выбор отрасли функционирования АСУТП

Отрасль: Электроэнергетика

Наименование АСУТП: Автоматизированная система оперативно-диспетчерского управления объектами электроэнергетики (АСОДУ)

Шаг 1–2. Границы моделирования
Учебная АСУТП: Как описано в задании, это распределённая автоматизированная система управления географически рассредоточенными технологическими процессами (подстанциями, распределительными устройствами), находящимися на расстоянии нескольких километров. Обмен данными и передача команд управления осуществляются только по проводным каналам связи.


Объекты защиты (компоненты АСУТП):


Серверы (SCADA-серверы, коммутационные серверы, серверы реального времени), в том числе виртуальные
Рабочие станции (клиентская часть SCADA-системы)
Телекоммуникационное оборудование
Каналы связи (проводные)
Мобильные устройства (инженерные станции)
